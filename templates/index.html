About This Model

This is a discrete-event simulation of a hospital triage system using SimPy. Key features:

  • Stochastic arrivals: Exponential inter-arrival times
  • Priority queuing: 3 severity levels (Emergency, Urgent, Non-Urgent)
  • Monte Carlo: Run multiple replications for confidence intervals
  • Performance metrics: Wait times, throughput, service levels
